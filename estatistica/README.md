# Statistical Analysis Projects in R

**Linguagem:** R
**Foco:** Análise estatística, visualização de dados, testes estatísticos, relatórios reprodutíveis

---

## Sobre

Esta seção contém projetos demonstrando competências em análise estatística utilizando R. Os projetos cobrem desde análise exploratória básica até testes estatísticos avançados e criação de relatórios reprodutíveis.

---

## Competências Demonstradas

### Análise Exploratória de Dados
- Análise univariada e bivariada
- Estatística descritiva
- Visualização de distribuições
- Identificação de padrões e outliers

### Testes Estatísticos
- Testes de normalidade
- Testes de comparação de grupos (paramétricos e não-paramétricos)
- Testes de correlação
- Análise de variância

### Transformações e Normalização
- Padronização (Z-score)
- Normalização (Min-Max)
- Transformações matemáticas (log, raiz)
- Verificação de normalidade

### Relatórios Reprodutíveis
- R Markdown
- Documentação técnica
- Visualizações integradas

---

## Projetos

### [Análise Exploratória Univariada](./Aula01/)
Análise descritiva de variáveis individuais, incluindo estatísticas descritivas e visualizações de distribuições.

**Técnicas:** Estatística descritiva, histogramas, boxplots, gráficos de barras

### [Análise Exploratória Bivariada](./Aula03/)
Análise de relações entre duas variáveis, incluindo correlações, tabelas de contingência e comparação de grupos.

**Técnicas:** Correlação, tabelas de contingência, gráficos de dispersão, análise multivariada

### [Relatórios Reprodutíveis com R Markdown](./Aula04/)
Criação de relatórios profissionais combinando análise, visualizações e documentação.

**Técnicas:** R Markdown, knitr, documentação técnica, relatórios HTML

### [Transformações de Variáveis e Tamanho de Amostra](./Aula05/)
Técnicas de transformação de variáveis e cálculo de tamanhos amostrais para estudos estatísticos.

**Técnicas:** Normalização, padronização, Q-Q plots, cálculo de tamanho de amostra

### [Análise Estatística com Testes Não-Paramétricos](./Aula07/)
Aplicação de testes estatísticos paramétricos e não-paramétricos em dados reais de bike sharing.

**Técnicas:** Testes de normalidade, Wilcoxon, Kruskal-Wallis, ANOVA, análise temporal
